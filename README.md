# Simple Alarm

ブラウザで動く、シンプルなタイマー／アラームです。  
集中状態から「浮上する」ことを目的に、  
**残り時間に応じてビープ音の密度が変化する設計**になっています。

👉 https://doraiso.github.io/simple-alarm/

---

## コンセプト

- 時間を知らせるだけでなく  
  **集中 → 注意 → 焦り → 強制終了** を音で表現する
- 深く集中している作業（勉強・創作・実装）から戻るための補助ツール
- フロントエンドは「勉強」ではなく **遊びながら作るもの** という発想

---

## 機能

### ⏱ タイマー
- 分単位で時間を設定
- Start / Reset に対応

### 🔔 段階的アラーム音（ビープ音）
時間の残りに応じて、ビープ音の鳴り方が変化します。

- **3分前**
  - 弱めの合図音（そろそろ意識を向ける）
- **1分突入**
  - 合図として2音のビープ
- **残り59〜31秒**
  - 2秒おきに短いビープ（じわじわ焦らせる）
- **残り30〜1秒**
  - 1秒おきに短いビープ（明確に焦らせる）
- **0秒（タイムアウト）**
  - 強めのビープ音で強制的に浮上

※ すべて Web Audio API によるビープ音で構成  
※ 外部の音楽ファイル・効果音は使用していません

## 仕様・注意点

- ブラウザの仕様上、**バックグラウンドタブでは音が鳴らない場合があります**
  - 環境・ブラウザ・省電力状態により挙動が異なります
- フォアグラウンド（タブを開いた状態）での使用を想定しています
- 厳密なアラーム用途や商用利用よりも、  
  **個人利用・実験・遊び**を前提としています
