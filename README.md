# Simple Alarm

ブラウザで動く、シンプルなタイマー／アラームです。  
集中している状態から「浮上する」ことを目的に、  
**段階的にビープ音が変化する設計**になっています。

👉 https://doraiso.github.io/simple-alarm/

---

## コンセプト

- ただ時間を測るだけでなく  
  **「気づき → 注意 → 焦らせ → 強制終了」**を音で表現する
- 勉強・作業・創作など、  
  深く集中している状態から戻るためのツール
- フロントエンドの勉強というより「遊びながら作った道具」

---

## 機能

### ⏱ タイマー
- 分単位で時間を設定
- Start / Reset に対応

### 🔔 段階的アラーム音
時間の残りに応じて、ビープ音が変化します。

- **3分前**  
  - 弱めのビープ音（そろそろ意識を向ける合図）
- **1分前**  
  - 合図音 + 10秒おきの短いビープ
- **残り30秒**  
  - 1秒おきの短いビープ（焦らせフェーズ）
- **0秒（タイムアウト）**  
  - 強めのアラーム音で強制的に浮上

※ 音はすべて Web Audio API によるビープ音です  
（外部音源・音楽ファイルは使用していません）

### 👀 視覚的フィードバック
- 残り時間表示
- タイトルの更新・点滅による通知

## 仕様・注意点

- ブラウザの仕様上、**バックグラウンドタブでは音が鳴らない場合があります**
  - 環境やブラウザによって挙動が異なります
- フォアグラウンド（タブを表示している状態）での使用を想定しています
- 商用利用・厳密なアラーム用途よりも、  
  **個人利用・実験・遊び**を前提としています
